1. В качестве фреймворка для микрофронтендов я выбрал Webpack Module Federation.

- Простота настройки. У нас будет host-приложение, к которому мы будем подключать микрофронтенды. В будущем при создании новых фичей, будет просто создать микрофрондент и в хосте добавить его.
- Mesto использует один JS фреймворк (React), поэтому MF подходит для такой ситуации.
- Lazy-loading

Разбивать проект на микрофронтенды я буду на такие части:
- host - Главный микрофронтенд. В нем подключаются микрофронтенды с фичами. Также в нем лежат базовые комоненты страницы (Header, Footer, Main) и их стили.
- auth - микрофронтенд для работы с входом пользователя в Mesto. Он включает в себя региcтрацию, логин.
- user - микрофронтенд для работы с профилем пользователя. Он включает в себя редактирование профиля, обновление аватарки. Также он содержит общий контекст пользователя, чтобы использовать в других микрофронтедах.
- card - микрофронтенд для работы с карточками. Он включает в себя отображение списка карточек, их добавление/удаление, и работа с лайками.

Каждый микрофронтенд содержит в себе соответсвующие стили и компоненты Popup'ов.

Микрофронтенды используют dispatchEvent и EventListener для работы с событиями и передачи данных между компонентами(своих и чужих). Например, при добавлении карточки в компоненте AddPlacePopup, он отправляет событие и ListCard обновляет список.
Также используется React Context для хранения информации о пользователе и передаче ее между микрофронтендами.

3. Запуск проекта:

Запускать нужно в порядке:
- auth - Поднимается на 8081
- user - Поднимается на 8082 (Важно, чтобы он поднимался перед card, так как он использует его контекст)
- card - Поднимается на 8083
- host - Поднимается на 8080 (Запускается последним, так как он использует все микрофронтенды)

Нужно запустить каждый микрофронтенд отдельно. Для этого нужно:
- Перейти в каталог с микрофронтендом:
```bash
cd frontend/microfrontend/auth
```
- Установить зависимости в корне проекта:
```bash
npm install
```
- Запустить проект:
```bash
npm start
```
Бэкенд используется или локальный или на удаленном сервере. В случае локального, нужно его поднять и указать в файле api.js в каждом микрофронтенде локальный адрес. В случае удаленного, нужно указать удаленный адрес.
