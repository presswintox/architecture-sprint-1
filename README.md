Делим на микрофронтенды по Module federation 
Какие микрофронтенды будут в проекте:
- host - главный микрофронтенд, который будет подключать остальные микрофронтенды
- auth - микрофронтенд для авторизации(login, register, logout)
- user - микрофронтенд для работы с пользователями(редактирование, аватарки)
- card - микрофронтенд для работы с карточками(добавление, удаление, лайки)
